# Соответствие варианту 26

Источник: ИКБО-14-25.pdf, общие требования на стр. 4-7,
вариант 26 на стр. 83-85. Другие варианты не применяются.
Java выбран по прямому указанию пользователя.

| Требование | Реализация и доказательство |
| --- | --- |
| Этап 1: CSV как источник | Config.load, examples/*.csv |
| Четыре настройки | package, repository, test_mode, ascii_tree |
| Вывод ключ=значение этапа 1 | Stages.run, аргумент 1 |
| Ошибки всех параметров | ConfigTests, README, stderr, exit 1 |
| Этап 2: формат Maven | Coordinate, MavenRepository, Xml, PomModel |
| Прямые зависимости по URL | HttpClient и самостоятельный XML-разбор |
| Вывод прямых зависимостей | run.bat examples/junit.csv 2 |
| Запрет готового получения зависимостей | Только JDK; нет Maven API и сторонних импортов |
| Этап 3: DFS без рекурсии | Graph.traverse, ArrayDeque |
| Обработка циклов | GraphTests, сохранение рёбер, конечный вывод |
| Файл с именами A-Z | TestRepository, examples/repository.csv |
| Различные тестовые случаи | Ромб, цикл, самоссылка, лист, глубокая цепочка |
| Этап 4: обратные зависимости | Graph.reversed и Graph.dependents |
| Тот же алгоритм обхода | Graph.dependents вызывает Graph.traverse |
| Демонстрации обратного поиска | ReverseTests, reverse.csv, DEFENSE.md |
| Этап 5: PlantUML в stdout | Render.plantUml |
| ASCII по параметру | Render.ascii, ascii_tree=true |
| Три различных пакета | junit.csv, slf4j.csv, hamcrest.csv |
| Сравнение со штатным Maven | COMPARISON.md, comparison/*-maven.txt |
| Объяснение различий | Формат и границы сравнения описаны отдельно |
| Коммит каждого этапа | git log --reverse --format=full |
| README: функции, сборка, тесты, примеры | Корневой README и Javadoc |
| Публичный репозиторий | История локально готова; нужен адрес для публикации |

## Правила оформления

| Правила | Проверка |
| --- | --- |
| С1-С5 | README.md, .gitignore, src, tests, run.bat и run.sh |
| С6 | feat(scope): description, подробности в теле коммитов |
| Г1-Г5 | Нет архивов, бинарников, кешей, сборки, настроек редакторов |
| Р1 | Файлы не превышают 1000 строк |
| Р6 | Java-код не превышает 120 символов в строке |
| Ф4 | Java-методы не превышают 40 строк |
| А4 | Не более 7 параметров |
| К4 | Javadoc у типов и методов |
| Ц4 | Цикломатическая сложность до 10 |
| М4 | MagicNumber и отдельная проверка чисел в сравнениях |
| И4 | Java-соглашения имён, проверяемые Checkstyle |
| Правила других языков | Неприменимы: исходники и тесты только Java |

Проверки опубликованного перечня не являются запуском закрытой программы
преподавателя. Её результат без доступа к программе гарантировать нельзя.
