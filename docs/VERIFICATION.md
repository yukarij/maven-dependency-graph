# Проверка перед сдачей

Дата проверки: 08.11.2026. JDK 25.0.2, компиляция с --release 17.
Checkstyle 10.21.4 с конфигурацией из корня репозитория.

## Результат

- Восемь групп Java-тестов проходят: CSV, ошибки, POM, локальный HTTP,
  DFS, обратные зависимости, рендеринг и CLI всех пяти этапов.
- Checkstyle: ноль нарушений в src и tests.
- Все пять этапов имеют отдельные feat(scope)-коммиты с подробным телом.
- Проверены деревья файлов каждой версии: нет архивов, бинарников,
  классов, кешей, сборки и настроек редакторов среди отслеживаемых файлов.
- Исторические версии отдельно компилируются и проходят свои тесты;
  их Java-код также проходит итоговую конфигурацию Checkstyle.
- Проверены наличие README.md, .gitignore, src, tests и скриптов запуска,
  длина файлов до 1000 строк и длина строк до 120 символов.
- Checkstyle проверил методы до 40 строк, до 7 параметров,
  цикломатическую сложность до 10, Javadoc и соглашения имён Java.
- Проверены числовые литералы в сравнениях; значимые пределы вынесены
  в именованные константы. Индексы и шаги итерации не задают скрытых настроек.
- Сравнение с настоящим mvn dependency:tree выполнено для трёх пакетов;
  состав вершин и рёбра совпали. Исходный вывод сохранён в docs/comparison.
- Проверена сборка из чистой локальной копии, включая путь с пробелами.

## Самостоятельный повтор

Из корня проекта выполните:

```text
test.bat
git status --short
git log --reverse --format=full
git ls-files
```

Checkstyle JAR храните вне репозитория:

```text
java -jar PATH_TO_CHECKSTYLE.jar -c checkstyle.xml src tests
```

После сборки build может существовать на диске, но git status не должен
показывать его содержимое. .git - служебная база Git, а не отслеживаемые
исходные файлы; наличие в ней бинарных объектов нормально.
Текстовые результаты демонстраций в docs - документация, не артефакты сборки.

## Что ещё зависит от сдачи

Локальная история готова. Для выполнения требования о публичном доступе
её нужно отправить в публичный Git-репозиторий. Пока удалённый origin
не задан; доступ по внешней ссылке не проверен.
Загрузка отдельных файлов через веб-интерфейс не переносит историю этапов.
Нужно отправить ветку main целиком обычным git push.

Закрытая программа преподавателя не запускалась: у нас нет её кода
или исполняемого файла. Проверены все опубликованные категории нарушений,
но гарантировать результат неизвестной реализации проверки нельзя.
