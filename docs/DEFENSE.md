# Краткая подготовка к защите

## Что сказать в начале

«Я реализовал на Java инструмент анализа зависимостей Maven по варианту 26.
Все четыре настройки читаются из CSV. Программа сама скачивает POM через
HttpClient и разбирает XML средствами JDK. Менеджеры пакетов и сторонние
библиотеки для получения зависимостей внутри программы не используются.
Транзитивный граф строится DFS без рекурсии. Результат выводится текстом
PlantUML и, по настройке, ASCII-деревом».

## Основные понятия

Пакет здесь обозначен координатами groupId:artifactId:version.
Например, junit:junit:4.13.2. POM - XML-файл с метаданными пакета.
URL строится по схеме: groupId с точками, заменёнными на `/`, затем
artifactId/version/artifactId-version.pom.

Вершина графа - конкретная версия пакета. Ребро A -> B означает,
что A зависит от B. Прямая зависимость указана в POM самого A.
Транзитивная получается через другие пакеты: A -> B -> D.
Тогда D - транзитивная зависимость A.

## Как устроен обход

Graph.traverse хранит ожидающие обработки вершины в ArrayDeque.
В начале в стек кладётся корень. Пока стек не пуст, извлекается вершина.
Если она уже есть в построенном графе, повторная обработка пропускается.
Иначе загружаются прямые зависимости, сохраняются рёбра и дети кладутся
в стек в обратном порядке, чтобы сохранить порядок из исходных данных.

Это DFS: сначала углубляемся по одной ветке, затем возвращаемся к другим.
Рекурсивных вызовов нет, поэтому длинная цепочка не переполняет стек Java.
Тест строит цепочку из 20000 вершин. Каждый пакет разбирается при обходе
один раз; рёбра циклов остаются в результате. Сложность обхода O(V + E)
без учёта сети, XML и построения текста. V - число вершин, E - число рёбер.
Память графа и ожидающих вершин - O(V + E).

## Циклы и общие зависимости

При G -> H -> G повторная обработка G пропускается. Это останавливает
обход, сохраняя оба ребра. ASCII-вывод отдельно отслеживает активный путь:
возврат к его вершине помечается [cycle]. Если вершина встречалась
в другой ветке, выводится [shared]. Общая зависимость не является циклом.
Самоссылка F -> F также сохраняется и помечается как цикл.

## Обратные зависимости

Чтобы найти пакеты, зависящие от D, нужно перевернуть все рёбра,
а затем выполнить тот же DFS из D. В тестовом репозитории ответ:
B, A, E, C. E найден, потому что анализируется весь файл, а не только
граф потомков D. Целевой пакет исключается из собственного ответа.
По одному сетевому POM нельзя узнать всех его потребителей во всём Maven
Central; сетевой обратный поиск ограничен уже загруженным графом.

## Что показать преподавателю

1. `test.bat`: автономные тесты без JUnit и доступа к внешней сети.
2. `run.bat examples/test.csv 1`: четыре параметра ключ=значение.
3. `run.bat examples/junit.csv 2`: прямые зависимости из настоящего POM.
4. `run.bat examples/test.csv 3`: транзитивный граф ромба A-B/C-D.
5. `run.bat examples/reverse.csv 4`: обратные зависимости D.
6. `run.bat examples/test.csv`: PlantUML и ASCII с [shared].
7. В копии test.csv заменить package на G, затем F и I: цикл, самоссылка, лист.
8. `run.bat examples/junit.csv`, затем slf4j.csv и hamcrest.csv: три пакета.
9. В копии CSV поставить ascii_tree=false: останется только PlantUML.
10. Поставить test_mode=yes или неверный package: показать понятную ошибку.
11. Открыть docs/COMPARISON.md и исходный вывод Maven.
12. `git log --reverse --format=full`: отдельные этапы и Scoped Commits.

PlantUML - текстовый язык диаграмм. Строка `node0 --> node1` задаёт ребро.
Текст между @startuml и @enduml можно открыть в PlantUML-рендерере.
Встроенный рендерер изображений по заданию не требуется: требуется
сформировать и вывести описание. Передача данных внешнему сервису
для штатного запуска приложения не нужна.

## Почему Maven запускался отдельно

Запрет касается получения зависимостей самим приложением. В последнем
этапе прямо требуется сравнение со штатным инструментом. Поэтому Maven
использован только для независимого сравнения, не для построения нашего
графа. На трёх примерах вершины и рёбра совпали. Это не полный Maven
Resolver: ограничения и возможные причины расхождений перечислены
в docs/COMPARISON.md. Не утверждайте на защите, что поддержаны все
случаи разрешения зависимостей Maven.

## Какие файлы открыть, если спросят код

- Config.java: проверка четырёх параметров CSV.
- MavenRepository.java: HTTP, кеш, разрешение родителей и BOM стеком.
- PomModel.java: свойства, наследование и управление версиями.
- Graph.java: DFS без рекурсии и обратный граф.
- Render.java: PlantUML и конечный ASCII-вывод.
- tests/depgraph: проверки ошибок и граничных случаев на Java.

Понимание алгоритма и умение изменить входные данные важнее заучивания
формулировок. Перед защитой самостоятельно выполните команды выше.
